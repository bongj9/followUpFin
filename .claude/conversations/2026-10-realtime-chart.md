## 결정과 이유

- **데이터는 공식 API만.** 크롤링 안 함.
- **실시간 = 서버 웹소켓 1개 + 브라우저 SSE.** 토큰은 비밀이고 토스는 등록 IP만 받아서 브라우저가 직접 못 붙는다. 서버→화면 한 방향이라 SSE.
- **TradingView Advanced Charts는 못 씀.** 승인제이고 개인/취미 용도 불가. 무료 위젯은 지연 데이터. → 오픈소스 **Lightweight Charts**(Apache 2.0) + 토스 데이터.
- **보조지표는 브라우저에서 계산.** SMA, EMA, 볼린저(20,2), RSI(14, Wilder), MACD(12/26/9), 일목균형표(9/26/52).
- **LLM 요약 기능은 보류.** 유료 API 안 씀, Ollama도 원치 않음.

## 토스 API에서 알아낸 것

- 웹소켓 `wss://openapi-ws.tossinvest.com/ws/v1`, Bearer 헤더. 구독은 full-replace 배열 `[{"type":"trade:us","codes":[...]}]`. 60초마다 `PING` (180초 무송신 시 끊김).
- 계정당 웹소켓 최대 2개, 토큰 재발급 시 다른 인스턴스 토큰이 무효화됨 → **앱은 한 개만 띄울 것.**
- 캔들 `GET /api/v1/candles`는 `1m`, `1d`만 지원. `count ≤ 200`, `before`/`nextBefore`로 페이지. → 5분 이상은 1분봉, 주·월·년은 일봉을 서버(`LiveController`)에서 합친다. 년봉은 2002년부터, 약 3초.
- 1분봉 timestamp는 **봉 끝 시각**. 일봉은 한국 거래일 기준.

## 아직 안 한 것

- 차트 설정(톱니바퀴), 그린 선 저장(새로고침하면 사라짐), 패널별 범례
- B/S 매수·매도 표시, 평균단가 선 (보유 종목 조회 연동 필요)
- 업종 피드 기사 중복 제거, LLM 요약 버튼
- 회사 서버 배포(허가 받은 뒤 Docker) + 로그인/인증 — **공개 배포 전에 인증 필수**

## 주의

- 대화 중 토스 키가 채팅에 붙여넣어진 적이 있음 → **토스 키 재발급 권장** (실주문 가능한 키).
- 다른 컴퓨터에서는 `secret.example.yml`을 복사해 `secret.yml`을 만들고 키를 넣는다.
